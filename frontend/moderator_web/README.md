# moderator_web - Документация

> Веб-приложение для модераторов платформы **Migom** (агрегатор служб доставки).  
> Разворачивается на отдельном поддомене (например, `admin.migom.ru`).

## Что это

`moderator_web` - это B2B-интерфейс, через который модератор:
- Проверяет предприятия и меню, имеет возможность их блокировки
- Модерирует курьеров, имеет возможность ограничения их функционала
- Просматривает заказы, проверяет их выполнение
- Собирает аналитику по курьерам и заказам

## Быстрый старт

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # production build
pnpm lint       # ESLint
```

## Монорепозиторий

Проект является частью монорепозитория **Migom**. Бэкенд разрабатывается параллельно и располагается в соседних пакетах того же репозитория. При реализации фич API-схемы нужно согласовывать с актуальным состоянием бэкенда или смотреть в /docs openapi json-схемы.
