# Презентация: Migom - агрегатор доставки еды (Тайминг: ~5 минут)

## Слайд 1. Титульный слайд (0:00 - 0:30)
- **Заголовок:** Migom - агрегатор доставки еды
- **Подзаголовок:** Платформа для заказа еды с умным автоматическим поиском курьеров
- **Кейс:** Агрегатор для службы доставки
- **Спикер:** Иван

---

## Слайд 2. Проблема и цель решения (0:30 - 1:15)
**Проблема:** 
Высокий спрос на доставку сочетается с высокой стоимостью запуска собственной курьерской службы. Недостаточная насыщенность рынка специализированных сервисов формирует потенциал для новых проектов.

**Цель:** 
Создать современную платформу доставки, которая мгновенно и автоматически связывает покупателя, ресторан и курьера. Ядро решения - push-система предложения заказа, учитывающая радиус и геопозицию курьера.

---

## Слайд 3. Что реализовано в MVP (1:15 - 2:15)
- **Система ролей и доступов:** Изолированные кабинеты для Покупателя, Курьера, Владельца бизнеса и Менеджера точки.
- **Оформление заказа:** Управление несколькими корзинами по разным ресторанам, авторасчет стоимости доставки (до 2 км базовая, дальше - по километражу по координатам).
- **Умный поиск курьеров (Push-система):** Моментальный поиск ближайшего курьера по PostGIS и выдача ему оффера на 30 секунд. При игнорировании - оффер переходит следующему.
- **Realtime-отслеживание (WebSocket):** Обновление статусов заказа и передача геопозиции курьера клиенту в реальном времени.

---

## Слайд 4. Пользовательские сценарии (2:15 - 3:00)
1. **Покупатель:** Выбирает блюда (пиццу), указывает адрес на карте. Моментально видит смену статусов ("собирается" -> "в пути") и трекает курьера на карте через WebSocket.
2. **Владелец / Менеджер ресторана:** Получает push-уведомление о новом заказе, меняет статус на "готов к выдаче". Управляет каталогом, точками и наличием блюд.
3. **Курьер:** Открывает смену, задает свой радиус доставки. Получает автоматический Push-оффер заказа, принимает его в один клик, забирает еду и доставляет клиенту.

---

## Слайд 5. Техническая реализация (3:00 - 4:00)
**Микросервисная архитектура:**
- **Business Service (Python / FastAPI):** Управление пользователями, меню ресторанов, отзывами.
- **Delivery Service (Python / FastAPI):** Обработка корзины и заказов, сложная логика маршрутизации курьеров по гео-координатам (с помощью PostGIS). Отправка событий в Kafka.
- **Realtime Service (Go):** Выделенный WebSocket-хаб. Максимально быстро и с минимальным потреблением памяти рассылает события клиентам (read-only).
- **Инфраструктура:** PostgreSQL + PostGIS (хранение и гео-запросы), Redis (кэш, токены, бронь офферов), Kafka (асинхронная коммуникация), MinIO (файлы), Nginx (API Gateway).
