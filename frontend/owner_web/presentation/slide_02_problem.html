Проблема

Высокий спрос на доставку сочетается с высокой стоимостью запуска собственной курьерской службы. Недостаточная насыщенность рынка формирует потенциал для новых проектов.

Цель

Создать современную платформу доставки, которая мгновенно и автоматически связывает покупателя, ресторан и курьера через push-систему с учётом радиуса и геопозиции.
