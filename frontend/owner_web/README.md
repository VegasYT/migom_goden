# owner_web - Документация

> Веб-приложение для владельцев предприятий платформы **Migom** (агрегатор служб доставки).  
> Разворачивается на отдельном поддомене (например, `owner.migom.ru`).

## Что это

`owner_web` - это B2B-интерфейс, через который бизнес-владелец:
- Регистрируется и управляет своим аккаунтом
- Создаёт и настраивает организацию
- Формирует электронное меню / каталог товаров
- Указывает зоны доставки и торговые точки
- Просматривает входящие заказы
- Подключает торговую точку к своей точке Goden и связывает товары с блюдами Goden (кнопка "Goden" в карточке точки)

## Вход

Вход только через Keycloak Goden (единый вход, клиент `migom-web`, тема страниц Goden): регистрация и пароль - на странице Keycloak, кабинет получает токен через `keycloak-js` (`src/shared/auth/keycloak.ts`). Адрес Keycloak - `VITE_KEYCLOAK_URL` (по умолчанию `http://localhost:8180`), dev-сервер - порт 5174: на него клиент разрешает возврат. При первом входе нового пользователя кабинет спрашивает, кто он: владелец бизнеса или менеджер точки, и заводит его в Мигоме (`POST /api/v1/auth/session`).

## Быстрый старт

```bash
pnpm install
pnpm dev        # http://localhost:5174
pnpm build      # production build
pnpm lint       # ESLint
```

## Монорепозиторий

Проект является частью монорепозитория **Migom**. Бэкенд разрабатывается параллельно и располагается в соседних пакетах того же репозитория. При реализации фич API-схемы нужно согласовывать с актуальным состоянием бэкенда.
